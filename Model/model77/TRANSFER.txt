TRANSFER TO RUNPOD
==================

The destination must be below /workspace on the 250 GB Pod Volume so data and
checkpoints survive a stop/restart. Replace SSH_HOST and SSH_PORT with the
values shown by the RunPod Connect dialog.

From the parent of this local project directory:

rsync -ah --info=progress2 --partial --append-verify \
  -e "ssh -p SSH_PORT" \
  "Biohub - Cell Tracking During Development/" \
  root@SSH_HOST:/workspace/biohub/

Run the same command again after an interruption; --partial and
--append-verify avoid retransmitting completed file prefixes. Do not place the
84 GB data tree on the 30 GB container disk.

After transfer, on the Pod:

export BIOHUB_WORKSPACE=/workspace/biohub
cd /workspace/biohub
bash model77/install_cloud_env.sh
BIOHUB_STAGE=preflight bash model77/run_cloud.sh
BIOHUB_STAGE=smoke bash model77/run_cloud.sh

Only after both commands pass:

BIOHUB_STAGE=pilot bash model77/run_cloud.sh
BIOHUB_STAGE=baseline_eval bash model77/run_cloud.sh
BIOHUB_STAGE=pilot_eval bash model77/run_cloud.sh
BIOHUB_STAGE=compare_eval bash model77/run_cloud.sh

Download or sync model77/cloud_outputs and model77/evaluations before
terminating the Pod; termination also deletes its Pod Volume. No script in
this package uploads to Kaggle.
