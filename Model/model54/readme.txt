MODEL 54 — TOP-K/GAP GRAPH WITH ONE SPARSE DIVISION RESCUE

Status
------
Complete high-upside branch; independent visible validation remains pending.
This is not a submission.

Hypothesis
----------
The model53 global division-ranker branch improves the broad score but creates
too many forks. Model42 demonstrated that a tightly constrained, one-fork-per-
movie rescue can retain a rare true event without that failure mode. Apply the
unchanged model42 gate directly to model51's fork-free top-k/gap graph.

Protocol
--------
Use model51 CSV unchanged as the base. Score geometry candidates generated by
the frozen model36 ranker only as a feature table, then use model42's fixed
probability interval and spatial gates. At most one edge is added to a dataset
which has no existing fork. No thresholds are tuned on this experiment.

Promotion gate
--------------
Require an exact broad improvement and a separate visible-four regression
before considering this a production candidate.

Results
-------
The unchanged sparse gate adds seven structural forks, including one matched
division, and scores 0.9245866504: adjusted edge Jaccard 0.9045866504 plus
division Jaccard 0.20. This is +0.0200663921 over model51, but the division
gain is concentrated in a single training movie. It is therefore packaged as
model57 rather than replacing the conservative model56 default.
